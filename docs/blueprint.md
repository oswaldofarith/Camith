# **App Name**: AMI-FieldWorkManager

## Core Features:

- KPI Dashboard: Dashboard visualization of key performance indicators (KPIs) related to field work, such as 'Orders of the day,' 'Pending Jobs,' and 'Completed Jobs Today'.
- Interactive Map: Interactive map using Google Maps API to display routes, equipment locations, and real-time tracking of field teams.
- Dispatching Interface: Drag-and-drop interface for dispatchers to assign pending requests to field units on a map.
- Route Optimization: Suggest optimal routes, leveraging machine learning algorithms, for field teams considering real-time traffic conditions, technician skills, and equipment locations to minimize travel time and resource allocation.
- PDF Generation: Automated generation of work orders in PDF format, pre-filled with relevant details such as equipment information, task descriptions, and assigned technicians.

## Style Guidelines:

- Primary color: Deep Blue (#30475E) to convey trust, stability, and professionalism.
- Background color: Light Gray (#D6D5A8) for a clean, modern look that ensures readability.
- Accent color: Mustard (#FFC13B) to highlight key actions and important information, drawing user attention without overwhelming the interface.
- Body and headline font: 'Inter' sans-serif for a modern, neutral and highly readable appearance.
- Use simple, consistent icons from Material Design to represent different types of equipment, tasks, and statuses.
- Emulate the clear, card-based layout of Monday.com, to clearly display information. Use collapsible sections to organize detailed data and reduce clutter.
- Implement subtle transitions and loading animations to provide feedback to user actions and improve perceived performance.
